### I/ Why so many Distributions?

We learned some while ago that the linux system was one of the first operating systems to be released as an **open source**. The control it gave developers to have an environment that they can juggle with led to so many diverse distributions, following the areas of interest selected by each one of these many coactors. The four major families which took birth out of these diverse and multiple changes were :

**1/ Debian**
Best for beginners and tech guys who are willing to understand how day to day computing works.

**2/ Red Hat**
Suited for corporate IT. Running large and multiple servers and storing their data in the cloud.

**3/ Arch**
Customized for advanced Users, developers, and hardware enthusiasts.

**4/ Independent**
Implemented for Docker Containers, and very aged hardwares.

Before using one of them, you have to ensure the requirements needed for your computer fit the demand of the system. So constant bugs, malfunction and even the death of the machine can be avoided.

### II/ Installation of the Debian Distribution - Linux Mint

Before we dive into the procedure to personalize your computer with the linux system. We want to explain why we chose to lean on that particular distribution in the first place.

Linux Mint holds the advantage of requiring quite a minimum of _20GB_ for the **_system setup_** and _100GB_ for the **_disk storage_**, for an interactive and comfortable use.

It was released in 2006 by Clement Lefebvre and his team with the primary goal of being a **modern, elegant and comfortable** desktop operating system that works perfectly out of the **“consumer mode”** requiring **expert technical knowledge**. It approaches users friendly with a non-cluttered and simple user interface, easy to start and navigate. Offering you the ability to customize the system in regard to your learning model or the daily tasks you are usually performing.

The pre-requisites to install linux mint system are:

a computer with at least 120GB HDD and 2GB of RAM if it will be the only running system or at least 250GB HDD and 2GB of RAM if it will be sharing space with another system in the machine (dual boot system).

A partitioning software tool (like for e.g : rufus) installed in another machine that will help you create a bootable USB Drive, with a USB minimum size of 8GB.

And the procedure is as following :

– i/ download the latest stable version of linux mint in their official website online (https://linuxmint.com) inside another machine.

– ii/ format your 8GB usb drive and create a bootable USB Drive containing the linux mint iso downloaded using a partitioning software tool as for e.g “rufus”.

– iii/ Turn on the computer where you want to install linux. If it is a new one without a system installed it will prompt you to install one operating system. That’s quite our easy and ideal situation we can encounter before any installation.

– iv/ If it is a computer that already has a system you have to decide to _install linux_ as a _second system_ or as a _replacement_ of the first one. Whatever your choice. For more security, copy the data of the internal hard drive disk of your computer inside another external drive you must get.

– v/ Turn off that computer and plug in the USB Bootable Drive you created earlier.

– vi/ turn on the computer again. If the internal hard drive was empty (ideal situation) the machine will instantly boot on your USB Drive and open up the wizard setup system to follow before starting the installation.

– vii/ In case your computer already has a system installed. Wait approximately 2s after turning on your computer and start pressing multiple times the “ECHAP” or “ESC” key button until the “BIOS CoNFIG Menu” appears.

– viii/ Depending on your computer, hit the F9, F2, F12, or Fn key button to enter the “BOOT Options Menu”. Look at which one of these keys describe an entry corresponding to Boot options.

– ix/ Navigate the boot menu options with the _up/down keys_ button of the computer and move the **“USB Drive File”** over the top by using the (+) and (-) keys or the _F5_ and _F6_ function keys.

– x/ Then hit the “ESC” key button and you will be prompted to **SAVE** or **CANCEL** the change. Select **SAVE** and hit the “ENTER” Button.

– xi/ The computer will continue loading but will now start its programs from the USB Drive. Which will open the wizard setup installation.

– xii/ Read and Follow carefully the setup installation prompts popping up on the screen on each step you carry on until the system on itself starts loading.

**IMPORTANT :** There is generally one step in the wizard setup installation that needs to be treated attentively and carefully to avoid rewriting all the internal Hard disk Drive and losing both the already existing data and system. It is the INSTALLATION TYPE. With two main options. **Option 1 : “Install Linux Mint alongside Windows Boot Manager”** ; **OPtion 2 : “ERase Disk and Install Linux Mint”**. Choose **_option 1_** if you want to install linux as a second system in your computer, and **_option 2_** if you want to erase the entire old system and install linux mint in place and time.
